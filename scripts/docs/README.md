# Unpublished documentation consistency

Run `python scripts/docs/generate.py`, then `node --import ./scripts/test-support/register-tsx.mjs scripts/docs/validate.mjs`. Regeneration writes only the existing seven wiki pages and their two JSON records. It binds the exact six source/test files and the real UI source catalog to an immutable HEAD commit; these evidence files must match that commit even when unrelated working-tree files are dirty. It intentionally emits `dirtyDraft=true`, empty reviewers, null approved release and null last verified release. Do not interpret dirtyDraft as a clean-build assertion.

The manifest binds each page's locale, topic, known capability IDs and UTF-8 SHA-256. The link report binds local target bytes and heading anchors; HTTPS links, if present, are explicitly unverified. Inputs, symlink components, nonregular files, changing files, oversized files, unknown fields/IDs, duplicate keys/IDs and missing or stale hashes fail closed. Local Markdown links use the bounded inline `[label](path#anchor)` grammar; these authored pages contain no reference links, HTML links or executable examples. New Markdown grammars or examples need an explicit checker extension before use.

`claims-register.json` holds canonical DATA02 descriptions plus exact local evidence and real UI copy-key mappings. Canonical `CLAIM_COPY_BINDINGS` maps the six descriptions to existing `sourceCatalog` message IDs; each entry binds the exact message text SHA-256. The full catalog source byte hash must also match the immutable source commit, so any label edit invalidates consistency until reviewed regeneration. Descriptor-safe copy access rejects getters rather than evaluating them. The validator generates the 0.12.7 ClaimsRegister projection, preserving text/preconditions/exclusions from those records; it never grants review authority. The complete link/hash report is printed to stdout and can be retained by CI. Engineering consistency is **not semantic review, professional cryptographic review, publication, host verification or release approval**. Wiki publication and those approvals remain pending. No default runtime trust seam is installed by this tool.
