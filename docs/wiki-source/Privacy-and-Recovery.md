# Privacy, encryption and recovery
**Status: implemented foundations, not qualified for real private data.** The encrypted local vault (authenticated IndexedDB records), explicit ciphertext export, fresh-key backup recovery and encrypted local chat history exist and are covered by local tests. Diagnostics are redacted and exported only when the user selects them.

Encrypted local vault and optional encrypted backups protect selected content from casual local disclosure, but not compromised browsers, malicious extensions, payment processors or network metadata observers. Blockchains expose transaction facts. Browser storage can be evicted, and deletion cannot guarantee physical erasure. Backups should be encrypted before export, use a strong user-held passphrase and be tested for recovery without a server. Do not promise unlinkability, anonymity or final settlement without evidence.
