# Architecture and developer setup
**Planning only.** The project uses a static client-first architecture, user wallets, on-chain escrow and optional peer messaging; exact stack and chain support remain design decisions. Begin with the [master roadmap](../../00_PLANNING_AND_THREAT_MODELING/feature_0.12_product_completion/module_0.12.1_master_plan/spec-completion-roadmap-and-dependencies.md). Read the [reusable adapter staging guide](../../00_PLANNING_AND_THREAT_MODELING/feature_0.3_reusable_code/module_0.3.1_vendor_adapters/README.md). Keep wallet signing, transport, escrow, evidence and storage behind independently tested interfaces. Pin dependencies, run contract fuzz/invariant tests, avoid vendored cryptographic snippets, and retain architecture decisions and license provenance.
