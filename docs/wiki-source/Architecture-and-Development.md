# Architecture and developer setup

Implemented architecture is a static React/TypeScript/Vite client with native Worker boundaries, encrypted IndexedDB, domain authority separation and external-wallet interfaces. Local EVM/relay/message test modules do not enable trading in the default artifact. There is no mandatory app-owned account server or server-held spending key.

Run the commands in the [operator guide](../OPERATOR.md) and consult [development status](../DEVELOPMENT_STATUS.md). Specifications and structural audits are design/consistency evidence, not semantic acceptance. Preserve exact source revisions, dependency locks, protocol vectors, source licenses and asset digests. Accessibility, localization and mobile behavior need their recorded target matrix; local pseudo-locale checks do not prove WCAG or physical-device acceptance.
