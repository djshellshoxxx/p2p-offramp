# Unpublished wiki source

The seven named wiki pages are maintained local drafts. They are not a published
wiki or an approved release. The [consistency tool](../../scripts/docs/README.md)
binds their current bytes and local link targets without rewriting the pages.
`claims-register.json` records bounded description claims and immutable source
evidence; `docs-manifest.json` records the corresponding draft document inventory.

Reviewers remain empty, and approved release and last verified release remain
unset. A passing consistency check does not authenticate a reviewer or release,
enable trading, or publish the wiki. Regenerate the evidence records only after
reviewing the source changes and retaining an immutable source commit. Stale
historical evidence remains labelled stale until that update is qualified.
