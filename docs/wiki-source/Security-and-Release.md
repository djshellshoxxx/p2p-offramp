A signed manifest binds assets only under an actually selected trusted key; initial host/bootstrap trust remains separate. Check exact runtime identity, immutable escrow version and release provenance before any future enabled network flow.

No-script recovery instructions cannot decrypt a vault, sign, use a wallet, open a camera or prove current chain state. Use the supported recovery tool only after its trust prerequisites; never invent a downloadable approved binary from a source hash.

On conflicting native observations, unknown broadcast or compromised origin, stop economic actions, lock and preserve encrypted source data. Reconcile account/nonce and native finality before any explicit successor; never clear uncertainty because time passed. Report fixed error codes and public synthetic steps, not keys, payment instructions, raw provider errors or credentialed RPC URLs. Support must never request seeds.
