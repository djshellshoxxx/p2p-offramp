# Codespaces test lab
Codespaces is reserved for reproducible Docker-backed development and final testing. Once executable app code exists, configure a pinned devcontainer with Node, Foundry/Anvil, Playwright, mock relays, fault-injection and disposable test wallets. Use throwaway local keys or low-value testnet wallets only; never store production seeds in Codespaces or forwarded ports. Browser emulation does not replace testing on real iPhones, iPads and Android devices. GitHub Pages remains disabled until near-final release gates pass. See [Codespaces spec](../../00_PLANNING_AND_THREAT_MODELING/feature_0.12_product_completion/module_0.12.6_codespaces/spec-codespaces-test-lab-and-github-pages-release.md).
