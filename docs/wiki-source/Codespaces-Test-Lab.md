# Codespaces test lab

Local native browser and Anvil harnesses exercise synthetic flows and fault cases. Use only published disposable development keys, never production seeds or funded accounts. Do not expose a local RPC port publicly. A cloud test environment does not establish device security or deployment readiness.

A pinned linux/amd64 Node, Foundry and solc devcontainer recipe and fixed foundation/journey runner are implemented. Its local Docker build/tool and foundation checks are engineering evidence; no fresh Codespace or fresh npm-install qualification is implied. See the [lab recipe](../lab/README.md). Wiki hosting and independent Codespaces acceptance remain pending; this document does not claim a Codespace was provisioned. Browser emulation does not replace physical iOS/Android trials.
