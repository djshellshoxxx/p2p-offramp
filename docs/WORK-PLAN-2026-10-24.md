## Coordination

- **Integration branch:** `claude/sweet-noether-arf6ne`. Every worker runs in its own git worktree on its
  own branch, owns a disjoint directory, and commits there. The coordinator merges each worker as soon as it
  reports green, re-runs the full suite, and pushes. Later waves start from the merged head, so no work is redone.
- **Shared files** (`package.json`, `package-lock.json`, `tsconfig.json`, CI): workers add only their own
  entries; the coordinator resolves conflicts and regenerates the lockfile with `npm install`, never by hand.
- **Gate per merge:** `npm test`, `npm run typecheck`, `npm run check:specs`, `npm run test:browser`, plus any
  new package-specific suite (forge, cargo). A red worker branch is not merged.
- **Waves:** 1 = E1, E3, M1–M4, H1–H3 (independent). 2 = M5, M6, H4, H5 (need H1–H3, M2). 3 = M7–M9, E4
  (need wave 2). 4 = H6, H7, M10. 5 = H8. E2 runs after each wave.
- **Engineering rules:** strict TypeScript, fixed typed errors from `packages/domain`, no secrets in logs,
  bounded inputs, fail-closed defaults, tests first, comments matching existing density, no real funds.
