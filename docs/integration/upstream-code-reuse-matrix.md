# Upstream code reuse matrix (EVM MVP)

Date: 2026-11-11. Base: `main` `cdde998`. Branch: `claude/p2p-offramp-evm-escrow-vc7stk`.
Runtime used for evidence: Node v24.22.1, Foundry `1.5.1-v1.5.1` (`b0a9dd9`), solc 0.8.30
(sha256 `f3e987dc…428f7`, matches `scripts/sepolia/lib.mjs` `TOOLCHAIN`).

Rule applied: an upstream project is adopted only where it removes custom code or adds an
independent check without creating a second authority (account session, send path, relay
discovery, persistence). Runtime bundle additions need a demonstrated gap; dev-only test oracles
need only a qualification value. Licences: all candidates below are MIT or Unlicense; none is
copied into the tree (dependencies only), so `docs/REUSE.md` needs no new copied-code row.

## Provenance

- npm versions were chosen as the newest releases at least two weeks old on 2026-11-11 and are
  exact `devDependencies` in `package.json` / `package-lock.json`. Neither is imported by
  production sources (`npm run check:boundaries`) nor present in the web artifact
  (`npm run test:build-policy`). Top-level `@noble/*@2.4.0` runtime pins are unchanged.
- Transitive dev-only packages added: `ox@0.14.57`, `abitype@1.2.3`, `isows@1.0.7`, `ws@8.21.0`,
  `eventemitter3@5.0.1`, `@adraffy/ens-normalize@1.11.1`, `@scure/*`, `nostr-wasm@0.1.0`, nested
  `@noble/*` 1.x/2.0.x copies. All MIT/ISC/Unlicense per lockfile metadata.
