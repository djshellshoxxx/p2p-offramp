## Independent integration vectors

`scripts/vectors/g16_evm_independent.mjs` imports no application encoder or Noble implementation. It independently transcribes canonical G16 field order/ABI words and uses existing installed **js-sha3 0.8.0** (Keccak) and **elliptic 6.6.1** (ECDSA signing/recovery), both MIT. Provider source-file hashes and existing lock integrities are embedded in `packages/wallet/test/fixtures/g16-evm-independent.json`; no oracle package was added to this repository's dependencies. Public synthetic scalars 1 and 2 are test inputs and must never hold funds.

Six fixtures cover native/ERC-20, maximum integer widths, maximum registry-text widths/chain ID, and signed terms on distinct domains. They compare exact type hash, domain separator, struct hash, final digest, and seller/buyer recovery, with role/replay negative controls. Regeneration with the recorded installed tools was byte-identical. Four generated signatures and derived public keys were independently checked using installed Python cryptography 50.0.0 / OpenSSL 4.0.1. The checker supplies the existing 32-byte digest through `Prehashed`; it does not replace Keccak with SHA-256 or hash a second time.

Reproduce without installation or network:

```sh
node scripts/vectors/g16_evm_independent.mjs /workspace/GhostPay-pr30-validation/node_modules > /tmp/g16-regenerated.json
cmp packages/wallet/test/fixtures/g16-evm-independent.json /tmp/g16-regenerated.json
python3 scripts/vectors/check_g16_evm_openssl.py packages/wallet/test/fixtures/g16-evm-independent.json
python3 scripts/check-crypto-cache.py /workspace/.npm-cache
```

`check-crypto-cache.py` verified the existing cache archives' SHA-512 against the P2P lock, and every installed provider file against the verified archive: hashes 2.4.0, 60 files; curves 2.4.0, 72 files. It reads archives without extracting or executing them. This establishes local lock/archive/install correspondence, not the authenticity of the upstream Git commits or package publisher.
