## Method and limits
- Import graph: regex over `import`/`export from`/dynamic `import()`/`new URL` from the two entries, resolving relative specifiers, so barrel re-exports make files reachable without being bundled. Symbol-level use was checked by searching consumers of each export.
- Exports: `^export (function|const|class|let|enum)` over production sources; consumers classified as production, script (CLI/integration drivers) or unit test.
- Applications of patches were made in a scratch copy of `git archive HEAD` (not the repo). The scratch results are node unit suites and `tsc -p apps/web/tsconfig.ui.json`; no forge, anvil, browser or CI jobs were run. Hosted CI state of the open PRs was not queried.
- PR numbers from `gh api repos/.../pulls`; both #56 (earlier vibrant-cray PR) and #81 (draft) appear open. Re-verification at `46e2a7d` ran node unit suites and `tsc -p apps/web/tsconfig.ui.json` in a scratch copy; Solana results are the lead's.
