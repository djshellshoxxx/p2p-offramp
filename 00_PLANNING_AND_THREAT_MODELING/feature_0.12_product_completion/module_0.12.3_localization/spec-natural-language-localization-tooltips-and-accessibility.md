# Internationalization, natural-language guidance and comprehensive help
Internationalize all UI copy, errors, alerts, receipts, onboarding, tooltips, aria labels, dates/numbers and documentation. Launch reviewed locales en, fr, es, pt-BR, de, it, nl, ar, hi, zh-Hans, zh-Hant, ja, ko, id, tr, ru, uk, vi, th; expand via contributor workflow. English is source, not an assumption of users' literacy. Use ICU MessageFormat/Intl; avoid machine translation of legally material consent, irreversible fund instructions or safety warnings without human review. Locale selection explicit, browser preference as suggestion, never send language text to a cloud translation API by default.

Natural language: short sentences, define escrow, finality, chargeback, stealth, privacy and gas on first use; user-friendly errors include cause, safe next action and support link; explain what wallet will sign, what is public, who can reverse and what cannot be undone. No misleading security or anonymity promises.

Every actionable element and meaningful data element has a discoverable explanation: visible helper text for critical actions, hover tooltip on pointer, focus-triggered description on keyboard, tap-to-open help on touch. Never rely exclusively on title attribute or hover; use aria-describedby and accessible popovers. No tooltip should obscure a wallet confirmation or contain secret values. Maintain a tooltip registry with localization key, context, severity, link to docs and tests. Audit screen readers, RTL mirroring, pluralization, numerals, long German strings and CJK wrapping. WCAG 2.2 AA target.
